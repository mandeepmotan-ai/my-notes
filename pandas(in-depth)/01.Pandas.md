# Pandas

### 1. What is Pandas

- high-performance, open-source library built on top of NumPy
- designed for working with relational or labeled data easily and intuitively
- provides the "missing link" in Python: the ability to handle data in a way similar to SQL tables or Excel spreadsheets, but with the full power of Python’s programming capabilities.

### **2. Core Data Structures**

Pandas operates primarily on two structures. Understanding the difference is crucial for API usage and interview questions.

- **Series (1D):**
    - A one-dimensional labeled array capable of holding any data type (integers, strings, floats, etc.).
    - Think of it as a **single column** in an Excel sheet.
    - It has an **Index** (axis labels).
- **DataFrame (2D):**
    - A two-dimensional, size-mutable, potentially heterogeneous tabular data structure.
    - Think of it as the **entire spreadsheet** or a SQL table.
    - It consists of multiple Series objects sharing the same index.

### **3. Key Characteristics & Performance**

- **Built on NumPy:** Uses NumPy’s ndarray for storage, making it significantly faster than standard Python lists for large datasets.
- **Vectorized Operations:** Operations are applied to entire arrays without the need for explicit `for` loops, leveraging C-level optimizations.
- **Data Alignment:** Automatically aligns data based on labels (indices), preventing errors when joining datasets with missing or mismatched rows.
- **Handling Missing Data:** Provides robust tools (`NaN` handling) to detect, filter, or fill missing values (`.isna()`, `.fillna()`, `.dropna()`).

### **4. Why Pandas? (Interview Comparative Analysis)**

| **Feature** | **Standard Python (Lists/Dicts)** | **Pandas** |
| --- | --- | --- |
| **Performance** | Slow for large data (iterative) | Fast (Vectorized/C-based) |
| **Data Alignment** | Manual management | Automatic via Indexing |
| **Memory** | High overhead per object | Optimized memory usage |
| **Functionality** | Basic | Advanced (Merging, Pivoting, Time-Series) |
| **Missing Data** | Manual `None` checks | Built-in `NaN` support |

### **5. Interview Tips**

- **Mutable vs. Immutable:** Most Pandas operations return a *copy* of the data rather than modifying the original object.
    - *Tip:* While `inplace=True` exists in many methods, it is being deprecated in future versions. Always prefer re-assignment: `df = df.drop_all(...)`.
- **The "Index" Importance:** The Index is not just a row number; it is metadata. Understanding how to use the index effectively (e.g., for Time-Series) separates beginners from experts.
- **Broadcasting:** Just like NumPy, Pandas can perform operations between a scalar and a Series, or between Series of different shapes, through broadcasting.
