# Pandas Series

### **1. The Anatomy of a Series**

A Pandas Series consists of two main components:

1. **The Data:** A 1-D array of values (similar to a NumPy array).
2. **The Index:** A sequence of labels associated with the data.

**Interview Answer:** *"A Series is a one-dimensional labeled array capable of holding any data type. Unlike a NumPy array, a Series can be indexed by labels (strings, dates, etc.) rather than just integer positions, allowing for more intuitive data alignment and retrieval."*

### **2. Series Creation Patterns**

There are three primary ways to initialize a Series. Note the flexibility in how indices are handled.

### **A. From Lists (Default vs. Custom Index)**

- **Default:** If no index is provided, Pandas assigns an integer index starting from 0.
- **Custom:** we can explicitly define labels for your data.
- **Naming:** The `name` attribute acts as the "column header" when the Series is later converted to or joined with a DataFrame.

### **B. From Dictionaries**

- When passing a dictionary, the **keys** automatically become the **index**, and the **values** become the data. This is the most common way to create a single row or column manually.

---

### **3. Code Reference: Construction & Attributes**

```python
import numpy as np
import pandas as pd

# --- CREATION ---

# 1. Basic List to Series
country = ['India','Pakistan','USA','Nepal','Srilanka']
pd.Series(country) 

# 2. Custom Indexing & Naming
marks = [67, 57, 89, 100]
subjects = ['maths', 'english', 'science', 'hindi']
marks_series = pd.Series(marks, index=subjects, name='Nitish ke marks')

# 3. Dictionary to Series (Keys become Index)
marks_dict = {'maths':67, 'english':57, 'science':89, 'hindi':100}
marks_series = pd.Series(marks_dict, name='nitish ke marks')

# --- ATTRIBUTES (Metadata Inspection) ---

print(marks_series.size)      # Total number of items (4)
print(marks_series.dtype)     # Data type of values (int64)
print(marks_series.name)      # Returns 'nitish ke marks'
print(marks_series.is_unique) # Boolean: Are all values unique?
print(marks_series.index)     # Returns the Index object (Index(['maths', ...]))
print(marks_series.values)    # Returns the underlying data as a NumPy array
```

### **4. Loading Series from External Data**

When using `read_csv`, you can force the output to be a Series instead of a DataFrame if you are only working with a single column.

- **`index_col`:** Sets a specific column as the row labels.
- **`squeeze` (Legacy Note):** In older Pandas versions, `squeeze=True` converted a single-column DataFrame into a Series.
    - *Modern Tip:* In newer versions (Pandas 2.0+), use `pd.read_csv('file.csv').squeeze("columns")`.

```python
# Loading a single column as a Series
subs = pd.read_csv('/content/subs.csv').squeeze("columns")

# Loading with a custom index (e.g., Match Number as Index)
vk = pd.read_csv('/content/kohli_ipl.csv', index_col='match_no').squeeze("columns")

# Loading Bollywood movies with the 'movie' title as the Index
movies = pd.read_csv('/content/bollywood.csv', index_col='movie').squeeze("columns")
```

### **5. Interview "Knowledge**

- **Series vs. NumPy Array:** * A NumPy array only has implicit integer indexing.
    - A Series has **explicit labeling** (the Index).
    - Operations on two Series align data based on the **labels**, not the position.
- **The `is_unique` Attribute:** Useful for verifying Primary Key constraints during data cleaning.
- **Memory Efficiency:** The `.values` attribute returns a NumPy `ndarray`. Accessing `.values` is often faster for mathematical computations than working on the Series object itself, but you lose the index alignment.
- **The `dtype` Object:** If a Series contains even one string, the `dtype` will be `object`. If it contains an integer and a float, it will upcast to `float64`.

# **Pandas Series — Essential Methods**

### **1.Data Exploration & Sorting**

Series methods allow you to quickly "peek" into your data, understand its distribution, and reorder it for better analysis. Understanding the difference between sorting by **values** (the data itself) and **index** (the labels) is a common technical interview requirement.

### **2. Inspection Methods**

These are used to get a quick overview of the dataset without loading thousands of rows into memory.

- **`.head(n)` / `.tail(n)`:** Returns the first or last $n$ rows. Defaults to 5.
- **`.sample(n)`:** Returns a random sample of $n$ rows. This is statistically superior to `.head()` when checking for data bias or identifying patterns in large datasets.

### **3. Frequency & Distribution: `value_counts()`**

This is arguably the most important method for categorical data. It returns a Series containing counts of unique values.

- **Interview Tip:** By default, it sorts the result in descending order (highest frequency first). You can use `normalize=True` to get relative frequencies (percentages).

### **4. Sorting & The `inplace` Parameter**

Pandas offers two ways to sort: by the data (`sort_values`) or by the labels (`sort_index`).

| **Method** | **Description** | **Key Arguments** |
| --- | --- | --- |
| **`sort_values()`** | Sorts based on the actual data. | `ascending`, `inplace`, `na_position` |
| **`sort_index()`** | Sorts based on the row labels (Index). | `ascending`, `inplace` |

### **The "Inplace" Concept**

Most Pandas methods return a **new object** (a copy) by default.

- **`inplace=False` (Default):** The original Series remains unchanged. You must re-assign it: `df = df.sort_values()`.
- **`inplace=True`:** Modifies the original object directly and returns `None`.

---

### **5. Code Reference: Methods in Action**

```python
# --- 1. Inspection ---
subs.head()          # First 5 rows
vk.tail(10)          # Last 10 rows of Virat Kohli's IPL runs
movies.sample(5)     # 5 random movies for unbiased inspection

# --- 2. Frequency Analysis ---
# Find how many movies each actor/genre has
movies.value_counts() 

# --- 3. Sorting Values ---
# Find the highest score (Method Chaining example)
# 1. Sort Descending -> 2. Get top 1 -> 3. Extract the scalar value
highest_score = vk.sort_values(ascending=False).head(1).values[0]

# --- 4. Sorting Index ---
# Sort Bollywood movies alphabetically by movie title
movies.sort_index(ascending=False, inplace=True)

# --- 5. Permanent Sorting ---
# Sorting the 'vk' series permanently by runs scored
vk.sort_values(inplace=True)
```

# **Advanced Operations & Data Wrangling**

### **1. Statistical & Mathematical Operations**

Most of these methods exclude missing data (`NaN`) by default.

- **`count()` vs `size`:** `count()` returns the number of **non-null** items, whereas `size` returns the total number of elements including `NaN`.
- **`describe()`:** The "Swiss Army Knife" of EDA. It returns a summary including mean, std, min, max, and quartiles.
- **Aggregations:** `sum()`, `mean()`, `median()`, `mode()`, `std()`, `var()`.

### **2. Indexing & Slicing (Accessing Data)**

Series support multiple ways to retrieve data, making them more flexible than Python lists.

- **Integer Indexing:** Standard zero-based indexing. Supports negative slicing (e.g., `vk[-5:]`).
- **Label Indexing:** Accessing data using the index name (e.g., `movies['2 States']`).
- **Fancy Indexing:** Passing a list of indices to retrieve multiple specific elements at once: `vk[[1, 3, 5]]`.
- **Broadcasting:** Applying an arithmetic operation to the entire Series without loops (e.g., `series + 100`).

### **3. Boolean Indexing (Filtering)**

most powerful way to filter data. we create a "boolean mask" and pass it back to the Series.

- **Logic:** `vk[vk >= 50]` filters the Series to show only scores of 50 or more.

### **4. Essential Methods for Data Cleaning**

| **Method** | **Purpose** | **Interview Context** |
| --- | --- | --- |
| **`astype()`** | Changes the data type (e.g., `float64` to `int16`). | Critical for **memory optimization** in large datasets. |
| **`between()`** | Checks if values fall within a range (inclusive). | Useful for filtering specific demographics or price ranges. |
| **`clip()`** | Caps values at a specific floor and ceiling. | Excellent for **handling outliers** without deleting data. |
| **`drop_duplicates()`** | Removes redundant entries. | Use `keep='last'` or `keep='first'` to control which stays. |
| **`isnull()` / `dropna()`** | Detects or removes missing values. | Fundamental for preparing data for Machine Learning. |
| **`fillna()`** | Replaces `NaN` with a specific value (e.g., the mean). | Known as "Imputation" in data science. |
| **`isin()`** | Filters based on a list of allowed values. | Cleaner than using multiple OR (`|`) conditions. |

### **5. Functional Programming: The `apply()` Method**

The `.apply()` method allows you to execute custom logic (via functions or lambdas) on every element of the Series.

- **Interview Tip:** While powerful, `apply()` is generally slower than vectorized operations. Use it only when a built-in Pandas function doesn't exist.

### **6. Code Reference: Advanced Workflows**

```python
import numpy as np
import pandas as pd

# --- 1. Memory Optimization ---
# Reducing memory footprint by changing data type
vk_small = vk.astype('int16') 

# --- 2. Data Cleaning (The Pipeline) ---
temp = pd.Series([1, 2, np.nan, 5, np.nan, 10])
clean_temp = temp.fillna(temp.mean()) # Impute missing values with average
temp_no_nulls = temp.dropna()         # Or just drop them

# --- 3. Outlier Handling ---
# Keep all values between 100 and 200; anything outside is capped at these limits
capped_subs = subs.clip(100, 200)

# --- 4. Custom Logic with Apply ---
# Example: Categorizing performance
performance = subs.apply(lambda x: 'High' if x > subs.mean() else 'Low')

# --- 5. Membership & Logic ---
# Finding specific scores efficiently
special_scores = vk[vk.isin([49, 99, 100])]

# --- 6. The Copy Warning (Crucial!) ---
# Shallow Copy (view): Changing 'new' changes 'vk'
new = vk.head() 
# Deep Copy: 'new_safe' is independent of 'vk'
new_safe = vk.head().copy()
```

### **7. Interview Tips**

- **Deep vs. Shallow Copy:** * In Pandas, taking a slice (e.g., `new = vk.head()`) often creates a **view**, not a copy.
    - Modifying `new` might trigger a `SettingWithCopyWarning` or unintentionally modify the original `vk`.
    - **Always use `.copy()`** when you intend to create a standalone subset for modification.
- **The Power of `isin()`:** Interviewers often ask how to filter a dataset based on a list of 10 different categories. Using 10 `OR` statements is amateur; using `.isin(list_of_cats)` is the professional approach.
- **Vectorization over Loops:** Never use a `for` loop to add a value to a Series. Explain that Pandas uses **vectorization** (SIMD - Single Instruction, Multiple Data) to perform calculations in parallel at the C-level.

### **8. Visualizing Series**

Pandas integrates directly with Matplotlib.

- `series.plot()`: Default line plot (good for time-series/trends).
- `series.value_counts().plot(kind='pie')`: Great for visualizing categorical distributions.
