# DataFrame Mathematics & Data Selection

### **1. The Axis & Selection Logic**

In a DataFrame, operations can be performed either vertically (down columns) or horizontally (across rows).

- **Axis 0 (Index):** Operations happen "downwards." (e.g., sum of all rows in a column).
- **Axis 1 (Columns):** Operations happen "sideways." (e.g., sum of all subjects for one student).

**Interview Answer:** *"For data selection, I use `iloc` for position-based indexing and `loc` for label-based indexing. A key distinction is that slicing with `loc` is inclusive of the stop index, whereas `iloc` follows standard Python slicing where the stop index is exclusive."*

### **2. Mathematical Methods & The Axis Parameter**

Pandas allows for efficient aggregation. The `axis` argument is the most important concept here.

- **`sum(axis=0)` (Default):** Summarizes each column. The result is a Series where the index contains the original column names.
- **`mean(axis=1)`:** Calculates the average across the rows. Useful for calculating a student's average grade across multiple subject columns.
- **`var()` / `std()`:** Measure data spread. High variance indicates high volatility or diverse data points.

### **3. Selecting Columns**

Accessing columns is straightforward but has a "return type" catch:

- **Single Bracket `df['col']`**: Returns a **Series**.
- **Double Bracket `df[['col1', 'col2']]`**: Returns a **DataFrame**.
    - *Pro-Tip:* Even if selecting one column, using double brackets `df[['col']]` keeps the result as a DataFrame, which is often required for certain machine learning libraries.

### **4. Selecting Rows: `iloc` vs `loc`**

| **Feature** | **iloc** | **loc** |
| --- | --- | --- |
| **Search Basis** | Integer Position (0, 1, 2...) | Index Labels ('nitish', '2024-01-01') |
| **Slicing Stop** | **Exclusive** (like Python lists) | **Inclusive** (includes the end label) |
| **Use Case** | When you know the row number. | When you know the row name/ID. |

### **5. Code Reference: ath & Selection**

```python
import pandas as pd

# --- 1. Math Operations ---
# Column-wise sum (Total marks, total iq for all students)
students.sum(axis=0) 

# Row-wise mean (Average score per student across their subjects)
students.mean(axis=1)

# --- 2. Column Selection ---
titles = movies['title_x'] # Returns a Series
subset = ipl[['Team1', 'Team2', 'WinningTeam']] # Returns a DataFrame

# --- 3. Row Selection via iloc (Position) ---
movies.iloc[5]          # 6th row (index 5)
movies.iloc[:5]         # First 5 rows (0 to 4)
movies.iloc[[0, 4, 5]]  # Fancy indexing: 1st, 5th, and 6th row

# --- 4. Row Selection via loc (Label) ---
# Selecting by the student's name index
students.loc['nitish'] 

# Fancy indexing with labels
students.loc[['nitish', 'ankita', 'rupesh']]

# Slicing with labels (CRITICAL: 'rishabh' is INCLUDED)
students.loc['nitish':'rishabh':2]
```

# **Advanced Selection, Filtering & Feature Engineering**

### **1. Simultaneous Selection (Rows & Columns)**

You can filter both dimensions at once by passing two arguments to `iloc` or `loc`.

- **Format:** `df.loc[row_selection, column_selection]`

| **Method** | **Row Logic** | **Column Logic** | **Slicing Behavior** |
| --- | --- | --- | --- |
| **`iloc`** | Integer indices | Integer indices | Exclusive of stop index |
| **`loc`** | Label names | Label names | **Inclusive** of stop index |

## **2. Boolean Indexing (The "Masking" Concept)**

Filtering is done by creating a **Boolean Mask** (a Series of `True/False` values) and applying it to the DataFrame.

### **Logic Operators:**

- **AND (`&`)**: Both conditions must be true.
- **OR (`|`)**: At least one condition must be true.
- **NOT (`~`)**: Inverts the condition.

### **Examples from Code:**

- **Simple Filter:** `ipl[ipl['MatchNumber'] == 'Final']` (Isolates final matches).
- **Complex Filter:** `ipl[(ipl['City'] == 'Kolkata') & (ipl['WinningTeam'] == 'CSK')]`.
- **String-based Filter:** Using `.str.contains('Action')` to find specific genres within a string column.

### **3. Feature Engineering: Adding New Columns**

Adding columns is the core of "Data Enrichment."

1. **Scalar Addition:** `df['New_Col'] = 'Value'` (Assigns the same value to all rows).
2. **Derived Addition:** Creating a column based on existing data using `.apply()` or string methods.
    - *Example:* Extracting the lead actor by splitting a string: `movies['actors'].str.split('|').apply(lambda x: x[0])`.

### **4. Memory Optimization with `astype`**

In a professional setting, handling large datasets requires memory management.

- **Downcasting:** Converting `int64` to `int32` or `int16` can reduce memory usage by 50-75%.
- **The Category Dtype:** If a column has many repeating strings (like 'Team Name' or 'City'), converting it to `category` stores the strings once and uses integers under the hood.
    - *Code:* `ipl['Team1'] = ipl['Team1'].astype('category')`

### **5. Code Reference: Advanced Operations**

```python
import pandas as pd

# --- 1. Combined Selection ---
# iloc: rows 0-2, columns 0-2
movies.iloc[0:3, 0:3] 
# loc: rows 0-2, columns from title to poster (Inclusive)
movies.loc[0:2, 'title_x':'poster_path'] 

# --- 2. Practical Filtering (Interview Questions) ---

# Q: Percentage of matches where Toss Winner won the match?
toss_match_win_pct = (ipl[ipl['TossWinner'] == ipl['WinningTeam']].shape[0] / ipl.shape[0]) * 100

# Q: High rated action movies?
mask_action = movies['genres'].str.contains('Action')
mask_rating = movies['imdb_rating'] > 7.5
action_hits = movies[mask_action & mask_rating]

# --- 3. Adding Columns ---
movies['Country'] = 'India' # Scalar
movies['lead_actor'] = movies['actors'].str.split('|').apply(lambda x: x[0]) # Derived

# --- 4. Optimization ---
ipl['ID'] = ipl['ID'].astype('int32')
ipl['Team1'] = ipl['Team1'].astype('category') # Reduces memory for repetitive strings
```

### **6. Important Functions & Aggregations**

- **`value_counts()`**: Used to find frequencies.
    - *Example:* `ipl['WinningTeam'].value_counts()` shows which team won the most matches.
- **`sort_values()`**:
    - `df.sort_values(['col1', 'col2'], ascending=[True, False])`: Sorts by multiple criteria.
    - `na_position='last'`: Controls where `NaN` values appear in the sort.
- **String Methods**: `.str.upper()`, `.str.split()`, `.str.contains()`. These are vectorized and much faster than manual loops.

### **7. Interview Knowledge**

- **The `shape[0]` Trick:** When asked "How many...", always use `.shape[0]` (rows) instead of `len(df)`. It’s the standard Pandas way.
- **The `&` vs `and` Trap:** In Pandas, you **must** use `&` and `|` for bitwise comparison of Series. Using the Python keyword `and` will raise a `ValueError`.
- **Performance of `apply`:** While shown in the code for splitting strings, mention to the interviewer that `.str.split().str[0]` is often more "Pandas-native" and faster than using `.apply(lambda x: x[0])`.
