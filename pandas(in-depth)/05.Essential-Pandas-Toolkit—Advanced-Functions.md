# Essential Pandas Toolkit — Advanced Functions

### **1. Frequency & Ranking**

- **`value_counts()`**: Counts unique values.
    - *In DataFrames:* It identifies unique combinations of rows (useful for finding duplicate records).
    - *Interview Tip:* Use `normalize=True` to get the percentage distribution instead of raw counts.
- **`rank()`**: Assigns a rank to data points.
    - *Methods:* `average`, `min`, `max`, `first`, `dense`.
    - **Example:** Ranking batsmen by runs scored. `rank(ascending=False)` ensures the highest run-getter is Rank 1.

### **2. The Indexing Suite**

Mastering the index is what separates Pandas experts from beginners.

| **Function** | **Purpose** | **Key Detail** |
| --- | --- | --- |
| **`set_index()`** | Promotes a column to the index. | Useful for setting a Primary Key. |
| **`reset_index()`** | Demotes the index back to a column. | Use `drop=True` to discard the old index entirely. |
| **`sort_index()`** | Reorders rows alphabetically/numerically by index. | Essential for Time-Series data. |
| **`rename()`** | Changes specific column or index names. | Use a dictionary: `{'old_name': 'new_name'}`. |

### **3. Handling Missing Data (The Cleaning Pipeline)**

Data in the wild is messy. Pandas provides tools to handle `NaN` (Not a Number) values.

- **Detection:** * `isnull()` / `notnull()`: Boolean masks for missing/present data.
    - `hasnans`: A quick Series attribute to check if any nulls exist.
- **Removal (`dropna`):**
    - `how='any'`: Drops row if **at least one** value is missing.
    - `how='all'`: Drops row only if **all** values are missing.
    - `subset=['col']`: Only checks specific columns for nulls before dropping.
- **Imputation (`fillna`):**
    - Fills `NaN` with a constant, mean, or median.
    - `method='bfill'` (back-fill) or `'ffill'` (forward-fill): Inherits value from neighbors (common in finance).

### **4. Row & Column Management**

- **`drop_duplicates()`**: Removes redundant rows.
    - *Interview Question:* "How do you keep only the most recent entry?" **Answer:** `sort_values` by date, then `drop_duplicates(subset='ID', keep='last')`.
- **`drop()`**: Removes specific rows by index or columns by name.
- **`unique()` vs `nunique()`**:
    - `unique()`: Returns a NumPy array of unique values (includes `NaN`).
    - `nunique()`: Returns the **count** of unique values (excludes `NaN` by default).

### **5. Functional Power: `apply()`**

The `.apply()` method is used to pass a function along an axis of the DataFrame.

- **Axis 0:** Applies function to each column.
- **Axis 1:** Applies function to each row.
    - *Example:* Calculating Euclidean distance between two coordinate points stored in the same row.

### **7. Interview Knowledge**

- **`nunique()` and NaNs:** Remember that `nunique()` ignores `NaN` by default. If you need to count them, use `dropna=False`.
- **`inplace` Warning:** Remind the interviewer that `inplace=True` is efficient but prevents method chaining and is being phased out in newer Pandas versions in favor of explicit assignment.
- **Memory Management:** `drop()` does not actually free up memory immediately in Python; it just removes the reference. To truly optimize, downcast types using `astype()`.
- **Deep vs Shallow Copy:** Always use `.copy()` when creating a subset. If you don't, modifying `df2 = df1.head()` might change `df1` because `df2` is just a "view" of the memory.

### **8. Specialized Selection: `nlargest` & `nsmallest`**

Instead of `sort_values().head(5)`, use:

- `df.nlargest(5, 'column_name')`
- It is more performant because it doesn't sort the entire DataFrame; it uses a heap queue algorithm ($O(n \log k)$).
